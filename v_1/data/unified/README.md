# unified/ — Merged Corpus + Splits

The unified Akkadian dataset combining all three source corpora. This is the main dataset used for model training.

## Files

| File | Description |
|------|-------------|
| `unified_corpus.parquet` | Full merged corpus — all sources combined |
| `train.parquet` | 80% split — 32,343 texts, 1,960,636 words |
| `val.parquet` | 10% split — 4,042 texts, 253,798 words |
| `test.parquet` | 10% split — 4,044 texts, 235,660 words |
| `dataset_stats.txt` | Summary statistics (word counts, source distribution, split sizes) |
| `eda_summary.txt` | Detailed EDA summary (language dist, tokenization stats) |
| `*.png` | EDA plots: source distribution, text lengths, word volume, sign frequency, etc. |

## Dataset Scale

- **Total words:** 2,450,094
- **Total texts:** 40,429
- **Unique signs:** 16,748
