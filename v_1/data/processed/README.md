# processed/ — Per-Source Cleaned Corpora

Output of the source-specific preprocessing scripts (steps 02–04). Each subfolder contains one cleaned corpus in `.parquet` format, standardized to a common schema.

## Subfolders

### `ebl/`
- `ebl_corpus.parquet` — Cleaned eBL (Electronic Babylonian Library) corpus.
- **Generated by:** `src/corpus/02_process_ebl.py`
- **Input:** `raw/zip/full_corpus_dir.zip`
- **Scale:** ~998K words

### `archibab/`
- `archibab_corpus.parquet` — Cleaned Archibab corpus.
- **Generated by:** `src/corpus/03_process_archibab.py`
- **Input:** `raw/archibab.csv`
- **Scale:** ~66K words

### `oracc/`
- `oracc_corpus.parquet` — Cleaned ORACC corpus.
- **Generated by:** `src/corpus/04_process_oracc.py`
- **Input:** Downloaded via `src/corpus/01_download_oracc.py`
- **Scale:** ~1.39M words

*(The merged unified corpus has been promoted to `data/unified/` — see `../unified/README.md` for details.)*

*(Chungrong CSVs moved to `raw/chungrong/` — see `raw/README.md` for details.)*

## Loose Files

| File | Description |
|------|-------------|
| `oracc_cdli_metadata.parquet` | ORACC fragments matched with CDLI catalog metadata. Join result from `src/corpus/08_cdli_join_diagnostic.py`. Used by evaluation pipeline to get period/genre labels for ORACC texts. 11,059 matched P-numbers (99.4% match rate). |

## Common Schema (all per-source parquets)

Columns: `fragment_id`, `fragment_line_num`, `index_in_line`, `word_language`, `domain`, `place_discovery`, `place_composition`, `value`, `clean_value`, `lemma`
