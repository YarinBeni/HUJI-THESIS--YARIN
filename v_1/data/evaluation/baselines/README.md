# evaluation/baselines/ — Baseline Model Outputs

Predictions and metrics from baseline LLM runs on the evaluation corpora.

## Files

| File | Description |
|------|-------------|
| `baseline_predictions.parquet` | Aggregated predictions from all models (period + domain classification) |
| `baseline_predictions_10texts.csv` | Sample of 10 texts with predictions (for quick inspection) |
| `baseline_metrics.json` | Aggregate accuracy/F1 metrics for baseline model |
| `baseline_results_report.md` | Human-readable baseline evaluation report |
| `cache/` | Per-model raw prediction files (`<model-name>.jsonl`); resume-safe caches |

## Generated By

- `src/evaluation/03_llm_baseline.py` → `cache/<model>.jsonl`
- `src/evaluation/04_aggregate_results.py` → `baseline_predictions.parquet`
- `src/evaluation/05_evaluate_baseline.py` → `baseline_metrics.json`, `baseline_results_report.md`
