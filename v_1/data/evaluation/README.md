# evaluation/ — LLM Evaluation Data

All data for the LLM interpretability evaluation pipeline (Phase 1.5–2 of the thesis). Split into two subdirectories:

| Folder | Contents |
|--------|----------|
| `corpora/` | Curated evaluation test sets (input to the LLM pipeline) |
| `baselines/` | Baseline model predictions and aggregate metrics (outputs of the pipeline) |

## Corpus Design

Two contrastive groups of Akkadian letters, split by historical period:

| Corpus | Source | Period | Fragments | Words |
|--------|--------|--------|-----------|-------|
| Corpus A (`corpus_a`) | ARCHIBAB | 2nd millennium BCE (Old Babylonian) | 1,288 | 64,511 |
| Corpus B (`corpus_b`) | ORACC | 1st millennium BCE (Neo-Assyrian/Neo-Babylonian) | 3,775 | 272,622 |

The corpora are balanced to test whether LLMs / embeddings can distinguish temporal linguistic features across ~1,000 years of Akkadian.

## Baseline Results (gpt-oss-20b)

- Period classification accuracy: **22.2%** (on 10-text sample)
- Domain classification accuracy: **0.0%**
- Note: these are preliminary results on a small sample, not final evaluation.
