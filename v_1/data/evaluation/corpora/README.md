# evaluation/corpora/ — Evaluation Test Sets

Curated Akkadian letter corpora used as input to the LLM evaluation pipeline. These are **not** used for model training — held-out test sets for the interpretability evaluation.

## Files

| File | Description |
|------|-------------|
| `corpus_a_archibab_2nd_mill.parquet` | Corpus A — word-level rows for Old Babylonian letters |
| `corpus_b_oracc_1st_mill.parquet` | Corpus B — word-level rows for 1st millennium letters |
| `unified_3groups_akkadian_letters.csv/.parquet` | All 3 Chungrong groups merged at word level (includes Late Babylonian Group 3) |
| `texts_for_evaluation.jsonl/.parquet` | Text-level format — one row per text, with full transliteration. Used as direct LLM input. |
| `texts_token_stats.json` | Token length stats per text (for LLM context window planning) |
| `corpus_summary.json` | High-level corpus statistics |

## Generated By

- `src/evaluation/01_create_corpus.py` — creates `unified_3groups_akkadian_letters.parquet` from `raw/chungrong/`
- `src/evaluation/02_prepare_texts.py` — creates `texts_for_evaluation.*` from the unified parquet
