# evaluation/corpora/ — Evaluation Test Sets

Curated Akkadian letter corpora used as input to the LLM evaluation pipeline. These are **not** used for model training — held-out test sets for the interpretability evaluation.

## Files

| File | Description |
|------|-------------|
| `corpus_a_archibab_2nd_mill.parquet` | Corpus A — word-level rows for Old Babylonian letters |
| `corpus_b_oracc_1st_mill.parquet` | Corpus B — word-level rows for 1st millennium letters |
| `unified_3groups_akkadian_letters.csv/.parquet` | All 3 Chungrong groups merged at word level (includes Late Babylonian Group 3) |
| `texts_for_evaluation.jsonl/.parquet` | Text-level format — one row per text, with full transliteration. Used as direct LLM input. |
| `texts_token_stats.json` | Token length stats per text (for LLM context window planning) |
| `corpus_summary.json` | High-level corpus statistics |
| `seal_corpus.parquet` | **SEAL/DLL/LBPL fragment-level corpus (Phase A, 2026-04-07)** — see below |
| `seal_corpus_summary.json` | Per-corpus × per-label counts for `seal_corpus.parquet` |

## seal_corpus.parquet

Fragment-level corpus for the SEAL multi-task interpretability experiments.
Built by `v_1/src/corpus/02_build_seal_corpus.py` from the three word-level
CSVs in `v_1/data/raw/chungrong/seal_round4/`.

**Shape**: 384 rows × 15 columns

**Columns**:

| Column | Type | Notes |
|--------|------|-------|
| `fragment_id` | int64 | Globally unique across corpora |
| `corpus` | str | `seal` / `dll` / `lbpl` |
| `word_language` | str | Always `akk` |
| `domain` | str | `SEAL` / `DLL` / `LBPL` — the corpus-membership label |
| `period` | str | Raw, 7 values pre-normalization |
| `genre` | str | Lowercased + stripped (Section 5 normalization) |
| `sub_genre` | str / NaN | Lowercased + stripped; null for all DLL and LBPL fragments (103 nulls) |
| `provenance` | str | Raw, including compound values |
| `sub_provenance` | str | Raw, including compound values |
| `place_discovery` | NaN | Always null — not used |
| `place_composition` | NaN | Always null — not used |
| `word_count` | int64 | Words per fragment (range: 130–1382) |
| `text` | str | `clean_value` words joined by space (Chunrong's normalization; 4 dll rows fall back to `value`) |
| `text_tier0` | str | `clean_tier0(text)` — strips @-markup, non-breaking spaces, subscript-x |
| `text_maximal` | str | `clean_maximal(text)` — tier0 + 11 filters (digits, logograms, long vowels, etc.) |

**Per-corpus fragment counts**: SEAL=302, DLL=44, LBPL=38

**Data contract**: input CSVs are pinned by MD5 in
`v_1/data/raw/chungrong/seal_round4/inspection_report.json` (Phase 0).
Re-running `02_build_seal_corpus.py` aborts if any CSV changes.
