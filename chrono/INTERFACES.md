# chrono/ — module interfaces (the SLA between builders)

This file is the CONTRACT. Every module is built by a different agent, in
parallel, against this document — not against each other's code. If you need
something from a sibling module, code against the signature written here and
mark integration TODOs in your docstrings. Do not edit this file; if a
contract is impossible to satisfy, say so in your final report instead.

## 0. Ground rules

- **Ownership.** You create/modify files ONLY under the paths assigned to you.
  Sibling agents are editing other directories at the same time. Never run
  `git`. Never run repo-wide formatters. Run pytest only on YOUR test file.
- **Definition of done.** `python -m pytest chrono/tests/test_<yours>.py -q`
  passes locally, on CPU, in < 5 minutes, with no network and no GPU.
- **Determinism.** All randomness through `numpy.random.default_rng(seed)` or
  `torch.Generator().manual_seed(seed)`. No wall-clock in outputs.
- **Style.** Match the repo: a docstring header saying WHAT and WHY (see
  `v_1/src/phase2/transfer/e3_transfer.py` for the register), ~79 cols,
  no dead code, comments only for non-obvious constraints.
- **Env.** `/usr/local/bin/python` 3.11: torch 2.13 (CPU works), pandas,
  pyarrow, numpy, scipy, scikit-learn, pytest. NO torchsort, NO transformers
  locally (cluster only) — anything needing them must import lazily and tests
  must `pytest.importorskip`.

## 1. THE time convention (the trap that already bit this project once)

The corpus stores years **BC-positive** (Ashurbanipal = 631, larger =
EARLIER). Entity datasets elsewhere are CE-signed. In `chrono/` there is
exactly ONE convention, converted once at ingestion and never again:

> **t = astronomical year = −(BC-positive year). Larger t = LATER.**
> Every score `s` produced anywhere in chrono/ is a LATENESS score
> (larger = later). Every ordered pair (i, j) means t_i < t_j (i earlier).

`chrono.common.to_astro(year_bc)` does the conversion. Anyone found holding a
raw BC-positive year outside `chrono/data/` is wrong by contract.

## 4. Views contract (A2 owns)

Augmentation registry — canonical names, applied left-to-right, all pure
functions `(text, spans_dict, rng) -> (text, spans_dict)`:
`mask_ruler` (typed token `<RULER>` over ruler_spans), `strip_formula`
(rule library for royal-inscription openings/titulary/curses — regex over
text_eng; document precision expectations, min 5 words retained else flag),
`crop8|crop16|crop32|crop64` (contiguous word crop, deterministic by rng),
`orthonorm` (lowercase, collapse determinatives/diacritics variants for akk),
`drop_span` (random 10% word-span deletion).

`chrono/artifacts/views.parquet`: view_id (`{doc_id}::{lang}::{augs}+s{seed}`),
doc_id, lang ('akk'|'eng'), augs (comma string, '' = original), seed,
text, n_words, mask_count. API:
`augment.engine.build_views(corpus_df, menu: list[list[str]], seeds: list[int]) -> pd.DataFrame`
`augment.engine.sample_view_pair(doc_row, rng, menu_a, menu_b) -> (view_row_a, view_row_b)`
(branch B = milder menu). Confound audit: `augment.audit.confound_table(views_df) -> df`
(view_id, length, mask_count, sub_genre, provenance — consumed by HSIC/leakage).

## 5. Loss library (A3 owns; A4 consumes)

All `torch.nn.Module`-free pure functions over float32 tensors; every one
gradcheck-able (use double() inside tests).

```python
bt_loss(z_a, z_b, *, lambda_offdiag=5e-3, eps=1e-6) -> Tensor scalar
    # z: [B, D]; internally per-dim batch-standardized; on-diag → 1, off-diag → 0
softrank_loss(s, pairs, margins, *, temp=1.0) -> Tensor scalar
    # s: [N] lateness; pairs: Long[P,2] (i, j) with t_i < t_j; margins: [P] ≥ 0
    # mean softplus((s[i] − s[j] + margin)/temp) — pushes s[j] ≥ s[i] + margin
soft_spearman(s, t, *, temp=1.0) -> Tensor scalar in [−1, 1]
    # differentiable Spearman via all-pairs sigmoid soft-ranks (NO torchsort);
    # unit test: corr(soft, scipy.spearmanr) ≥ .99 at low temp on n=200
variance_loss(s, *, floor=1.0) -> Tensor scalar          # hinge on std(s)
hsic_loss(x, y, *, sigma_x=None, sigma_y=None) -> Tensor scalar
    # biased RBF HSIC, median-heuristic bandwidth when None; test vs x,x² dep.
graph_smoothness(s, edges, weights) -> Tensor scalar     # Σ w (s_i − s_j)²
interval_nll(mu, sigma, t) -> Tensor scalar              # gaussian NLL, sigma>0 via softplus upstream
class MonotoneCalibrator:      # numpy/sklearn, not torch
    fit(s: np.ndarray, t: np.ndarray) -> self            # isotonic s → t
    predict(s) -> np.ndarray
    predict_interval(s, coverage=0.8) -> (lo, hi)        # split-conformal residuals
make_order_pairs(doc_df, ruler_table, *, per_ruler_pair=21, seed) -> (pairs, margins, meta_df)
    # cross-ruler pairs ONLY where reign-proxy intervals are disjoint
    # ([t_min,t_max] non-overlapping); margin = gap between interval edges,
    # standardized; ZERO pairs for overlapping intervals (tested);
    # per-ruler-pair quota, weights balanced — mirror the spirit of
    # v_1/src/phase2/pairs/pairs_data.draw_pairs
```

## 7. Eval (A5 owns)

```python
mc_balanced_rho(scores: pd.Series, corpus_df, split: dict) -> np.ndarray   # ρ per draw, vs t
gkf_rho(scores_by_fold: dict[int, pd.Series], corpus_df, split) -> np.ndarray
placebo_rho(scores, corpus_df, split, seed) -> np.ndarray   # t shuffled within draw — must straddle 0
battery(scores_df: pd.DataFrame, corpus_df, splits: dict[str, dict]) -> pd.DataFrame
    # scores_df: doc_id, condition, s  (conditions: orig, mask_ruler,
    # strip_formula, crop16, ...) → rows: condition × split ×
    # {readout, rho_mean, rho_sd, n}
pooled_rho(scores, corpus_df, split) -> float          # REVIEW FIX (B1)
block_placebo_rho(scores, corpus_df, split, seed) -> np.ndarray
```
READ-OUT POLICY (review fix, wave B1). 39 of our 40 rulers carry exactly
ONE distinct year, so per-fold Spearman is undefined wherever a fold holds
a single ruler — true for leave-one-ruler-out (10/11 folds), for gkf's two
mega-ruler folds and for held-out-category folds. `battery` therefore
routes: `mc_balanced` → per-draw rho (readout='per_draw'); every other
split → ONE pooled rho over the concatenated held-out docs
(readout='pooled', n = docs). Averaging surviving folds instead would
silently report a WITHIN-reign number under an unseen-ruler label.

SIGNIFICANCE (review fix, wave B1). Because t is block-constant within
ruler, the exchangeable unit is the RULER, not the document. `placebo_rho`
(doc-level shuffle) stays as a LEAK DETECTOR; its band on the real
artifacts is ±.18, while the honest `block_placebo_rho` null is ±.50.
Every significance claim uses the block null; mc `rho_sd` is a
doc-resampling spread over 200 heavily overlapping draws sharing one fixed
8-ruler design — it is NOT a standard error and must never be divided by
√200.
